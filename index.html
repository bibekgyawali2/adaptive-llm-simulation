A browser version of the paper's simulator: the same GPU speed model (fitted to Vidur for Llama-2-7B), real request lengths from the Azure trace, the same deadlines, one router and monitoring data that is 0.5 s old. The trained model is replaced by a simple stand-in that knows each GPU's speed and slowdown. These numbers come from one live run, so they differ from the paper's results over 20 runs.
